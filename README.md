# Projeto Android — Curiosidades do Mascote

Pequeno site estático em HTML/CSS que apresenta a história e curiosidades sobre o mascote do Android (Bugdroid/Dandroids), criado como exercício didático.

## O que é
- Página simples com artigo, imagens e vídeo incorporado sobre a origem do mascote do Android.
- Objetivo: prática de HTML5 semântico, responsividade básica e organização de recursos estáticos.

## Estrutura
- `index.html` — página principal.
- `estilo/style.css` — estilos do site.
- `imagens/` — imagens usadas no artigo (bugdroid, dan-droids, etc.).
- `fontes/` — fontes personalizadas (ex.: `idroid.otf`).

## Como visualizar
Opções rápidas para abrir localmente:

- Abrir diretamente no navegador: abra `index.html` com duplo-clique ou `File → Open`.
- Servidor local (recomendado para evitar problemas com requisições relativas):

```bash
python -m http.server 8000
# então abra http://localhost:8000 no navegador
```

## Notas
- O projeto é estático — nenhum build ou dependência é necessária.
- Validação W3C executada e pequenas correções aplicadas (semântica e HTML5).
